How EquityLens works

EquityLens compares 2–3 Indian listed companies from the same sector. A planner checks the request, specialist AI analysts each judge one lens, a bull and a bear argue it out, and a judge gives the verdict. Code does every calculation and checks every AI claim; the AI reads, scores and explains.

Architecture

Everything runs in one Python process on Streamlit Community Cloud, redeployed from GitHub on every push. The orchestrator is the only part that calls the others. Every AI request goes through one wrapper, and every data source goes through one disk cache, so limits, retries and caching live in one place each.

How the scoring is done

Two things are computed side by side. Lane A decides the winner from the analysts' scores. Lane B compares the raw numbers lens by lens. The judge explains both, but only code decides who is stronger.

  • An analyst's score is relative: 5 means in line with the other companies in this comparison, not "average stock".
  • A winner is named only when it leads by at least 0.5 points out of 10. Below that the headline says it is too close to call.
  • A metric edge needs a clear gap: more than 5% better, or a small absolute gap for values near zero such as debt/equity. Near-ties show no edge.
  • The AI never sets a number. If its headline names a different winner, quotes a number that isn't in the facts, uses buy/sell wording, or mentions a metric that doesn't apply, the headline built from the numbers is shown instead.
3.1

How the weightage is done

Each analyst's score counts in proportion to its weight and to how confident it can be with the data it had. The weights are re-balanced twice so they always add up to 100%.

Confidence ceilings (set by code)

AnalystStarts atLowered by
Financials100%−10% per data warning · −10% if a bank or NBFC is compared · −15% if under 3 years of data (floor 30%)
News75%headlines only · −10% per company with fewer than 5 headlines (floor 30%)
Market data85%past prices only · −10% if a company lacks 3 years of prices · −10% if benchmark data is missing
Macro & sector70%indirect effect · −10% if there is no matching sector index
Social50%opinion, not evidence · −10% if a company has fewer than 5 posts

The confidence used is the lower of the AI's own confidence and this ceiling. In the example, Financials was capped at 90% because Infosys reports in USD (one data warning).

  • Base weights live in agents/planner.py (WEIGHTS): Financials 40%, News 20%, Market data 15%, Macro 15%, Social 10%. Social is low on purpose: opinion is not evidence.
  • The debate also sees each analyst's weight and confidence, so the bull and bear know Financials is the strongest evidence and News is headline-only.
  • Overall confidence uses the same numbers: the weighted average confidence (82.5% here) × (0.5 + 0.5 × share of planned weight that ran, 100% here) = 82% → High.
